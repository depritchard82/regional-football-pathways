# Regional Football Pathways

Independent UK football club research and application preparation for regional Australian families with players aged 15–18.

Website: https://depritchard82.github.io/regional-football-pathways/

## Hosting and updates

GitHub Pages serves `docs/` from the `main` branch. No build tools or server are required. Changes pushed to that folder publish automatically.

The directory contains 1,377 men’s club records and 150 women’s team records. Research snapshot: 17 October 2026. Application preparation and eligibility guidance reviewed: 18 October 2026. These dates describe research, not continuous verification. Historical entries and unknown requirements remain labelled.

Edit HTML, CSS and JavaScript in `docs/`. The public database snapshot is `docs/data.json`; blank downloadable templates are in `docs/templates/`. Keep all asset paths relative so the site works under its repository URL. `.nojekyll` disables Jekyll processing.

When updating from the original working project, copy only its reviewed `dist/` contents into `docs/`, retain `.nojekyll`, inspect the diff and push. Do not copy workbooks, private notes, credentials, hosting manifests or personal player documents. The earlier private Sites edition and this repository are separate deployments; updates do not automatically sync between them.

Local preview: `python3 -m http.server 8765 --directory docs`

## Family privacy

Shortlists, checklists, notes and budgets are stored in each visitor’s browser, not this repository. No player accounts, document uploads, bookings or emails are handled by this site. Moving from another domain does not transfer browser-local plans automatically. The plan export is a readable JSON backup; an import feature is not currently provided.

## Scope

This is an information resource, not a trial organiser, agent or eligibility assessment. Contact routes and programme rules need direct confirmation. Source links accompany research. Club names and third-party materials remain subject to their respective owners’ rights. No licence to third-party material is implied.
